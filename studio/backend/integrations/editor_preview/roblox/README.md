# Roblox Studio live preview

Install UnslothLivePreview.plugin.lua as a local Studio plugin on Windows or macOS. To do this in Roblox Studio, create a temporary Script, paste in the source and choose **Save as Local Plugin**. Remove the temporary Script from your place after saving the plugin.

In Unsloth Studio chat, select **Editor preview → Roblox Studio → Start preview**. In Roblox Studio, open **Unsloth → Live Preview**, paste the pairing code, and allow the requested viewport capture and loopback HTTP permissions. Keep the place in edit mode while previewing.
