# Blender live preview

In Blender, use **Preferences → Add-ons → Install from Disk** to install the downloaded zip and enable **Unsloth Studio Live Preview**.

In Studio chat, select **Editor preview → Blender → Start preview** and copy the pairing code. In Blender, press **N** in the 3D view and open **Unsloth**. Paste the code and select **Connect preview**.

The adapter follows the selected 3D view. Keep it open for the duration of the preview.
