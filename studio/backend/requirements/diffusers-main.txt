# OPT-IN ONLY. Never installed unless UNSLOTH_DIFFUSERS_MAIN=1 is set.
#
# A pinned commit of Diffusers main, for models whose support has merged upstream but has not
# reached a release yet. Today that is Qwen-Image-2.1: it merged on 2026-09-18, four weeks after
# 0.40.0 was cut, so 0.41.0 is the first release that can carry it and there is nothing on PyPI
# that works. Without this file the only way to try it is to break the release pin by hand.
#
# Why this is a SEPARATE file rather than an edit to diffusers-pin.txt. That file is the single
# source of truth for the release everything is built against, and it deliberately refuses a source
# build so installs stay reproducible and keep working behind a PyPI mirror with no route to
# github.com. Both properties are worth more than shipping one model early, so the default is
# untouched and this is something you ask for.
#
# Why a COMMIT and not a branch. Nothing in Unsloth can tell two builds of main apart: a git
# checkout reports 0.41.0.dev0 whatever it was built from, and ``_version_tuple`` truncates that to
# (0, 41, 0), so the family version gate reads any main build as satisfying 0.41.0. The commit is
# therefore the only thing actually pinning behaviour. It is also cheaper to check: for a full SHA
# ``_direct_reference_is_installed`` compares what is recorded in direct_url.json and needs no
# network, while a branch ref costs a git ls-remote on every pass.
#
# This exact commit is the tree the Qwen-Image-2.1 FP8 and INT8 artifacts were built and measured
# against, so what a user opting in gets is what was tested, not "whatever main was that day".
#
# Retiring this file: once 0.41.0 ships, bump diffusers-pin.txt to it and delete this. The family
# entry already records 0.41.0 as QwenImage21Pipeline's minimum, so nothing else has to move.
