# cmake. Skipping it on Intel Macs keeps that install compiler-free.
#
# Apple Silicon lags the pin: 1.3.0 onwards ships its arm64 wheel as macosx_14_0,
# which no macOS 13 host can install, and 1.3.0+ is also the only line with a cp314

# 1.0.1 on 3.14) while every other platform stays current. This mirrors the
# macOS 13 wheel handling already in single-env/constraints.txt for av and
# cryptography; collapse these back to one line once a macosx_13-tagged arm64
# wheel exists again.
