# The Diffusers release Unsloth is built against. THE single source of truth for it:
# no other requirements file may name diffusers, and a test in
# tests/studio/install/test_diffusers_pin.py enforces that.
#
# 0.42.1: FLUX.3 Image Klein arrived in 0.42.0 (0.41.0: Qwen-Image-2.1), and 0.42.1 stops a model
# repository from naming a module for from_pretrained to import. Exact pin, so installs are
# reproducible without a source build from GitHub.
#
# Why it is installed from its own file, in its own step: base.txt is applied near the
# start of the dependency pass. This step runs late, after every other requirements file,
# so nothing can re-resolve diffusers back to a release behind it.
#
# One line per Python floor, since an unmarked pin leaves the resolver nothing at all below it:
# 0.42.0 requires Python 3.11 and diffusers dropped 3.9 in 0.38. 3.10 and 3.9 hosts get the newest
# release they can take, and the family version gate refuses a model they lack with a clear message.
diffusers==0.42.1 ; python_version >= "3.11"
diffusers==0.41.0 ; python_version == "3.10"
diffusers==0.36.0 ; python_version < "3.10"
