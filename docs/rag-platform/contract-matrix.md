## Scan limits

- Query strings are dropped, so `?since=` variants collapse onto one route. Query parameters are part of the contract and are named in the transform column where they matter.
- Call sites that take a caller-supplied absolute URL, and those that consume server-minted signed URLs, carry no literal path and are therefore absent from the scan.
- External hosts (Hugging Face) are excluded: they are not part of the backend contract.
- Tauri IPC callers (`features/settings/api/launch-at-login.ts`, `features/native-intents/api.ts`) make no HTTP call and so have no row.
